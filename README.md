# Lore Master

Editor plugins that gather a project's lore. First feature: sync every Markdown file in
your workspace into Confluence (Cloud, Data Center, Server) with nesting, links, images
and Mermaid diagrams, and keep it in sync on every run.

- Plan and decisions: [`CLAUDE.md`](CLAUDE.md), [`ROADMAP.md`](ROADMAP.md)
- Architecture: [`docs/architecture/`](docs/architecture/)
- Work tracking: the GitHub issues (every step is an issue before it is built)

Built as an Nx monorepo with [`@mnci/cli`](https://github.com/russoedu/MoNecromanCi).
The repository name is still `MarkDoc` until the rename (#43).
